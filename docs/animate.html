AOS + Animate.css

Using external CSS libraries with AOS

Animate.css Integration

AOS can trigger animations from external libraries like Animate.css.
Just set useClassNames: true and map your animations!

Bounce In Left

data-aos="animate__bounceInLeft"

Bounce In Right

data-aos="animate__bounceInRight"

Flip In X

data-aos="animate__flipInX"

Flip In Y

data-aos="animate__flipInY"

Rotate In

data-aos="animate__rotateIn"

Zoom In

data-aos="animate__zoomIn"

Jack In The Box

data-aos="animate__jackInTheBox"

Roll In

data-aos="animate__rollIn"
